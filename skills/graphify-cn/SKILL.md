# Graphify CN

将中文需求映射到 Graphify 的现有提取、构建、查询和导出流程。使用 Python 引擎 `graphifyy`；本技能不安装运行时、不自带模型服务。

## 选择入口

- 用户需要已有图谱的数量、证据类型和连接分布：使用 `graphify-cn digest [graph.json]`，无需模型。默认位置为项目根目录的 `graphify-out/graph.json`；可用 `--output` 写入一个新 Markdown 文件。
- 用户明确要求建立图谱、更新图谱、查询内容或追踪路径：先读 [WORKFLOW.md](WORKFLOW.md)，沿用完整流程。该文件保留原 `/graphify` 名称；本入口将同样的请求交给该流程，命令和 Python 模块名不翻译。
- 单个符号的一次性定位且没有图谱：按原工作流判断是否先做直接搜索，不自动将整个目录送去语义提取。

## 中文交互

用中文解释问题、图谱结构和结果；保留代码符号、节点 ID、文件位置和关系方向。未知证据不写成直接提取；`EXTRACTED`、`INFERRED`、`AMBIGUOUS` 沿用原含义，并引用真实 `source_location`。中文称谓和英文标识可能指同一概念时，按图中实际词汇扩展查询，不擅自合并节点。

代码 AST 提取在本地运行。文档、PDF、图片的语义提取依赖助手模型或配置的后端，执行前说明当前路径、输入类型、模型方式及费用/数据流向；不能把它们统称为完全免费离线。尊重用户指定目录和已有授权，不扫描无关材料、不自动接入云服务。

## 命令与验证

`graphify-cn digest` 是新增的中文统计命令；其他 `graphify-cn` 子命令转发给现有引擎，原 `graphify` 命令继续可用。没有安装新增入口时，不伪造执行成功，可先按 README 安装本仓库，或继续使用已有原引擎。

只有实际执行完成才报告生成文件和节点数量。统计摘要不读取原文件核对语义、不判断材料是否最新，不推断 token 节省比例。写入、数据库推送、hook、watch 和云服务操作仍按当前任务授权范围执行。
